# Tapicería El Carmen

Sitio web oficial de Tapicería El Carmen - Tapizados profesionales en Atlixco, Puebla.

## 🌐 Sitio en producción

**URL**: [https://tapiceriaelcarmen.com](https://tapiceriaelcarmen.com)

## 📋 Descripción

Sitio web profesional para Tapicería El Carmen, especializada en:
- Retapizado de sofás y salas
- Tapizado de sillas y comedores
- Cabeceras personalizadas
- Muebles a medida
- Modificaciones de muebles

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- Cloudflare Pages (hosting)
- GitHub (control de versiones)

## 📁 Estructura del proyecto

```
tapiceriaelcarmen/
├── index.html          # Página principal
├── styles.css          # Estilos del sitio
├── script.js           # Funcionalidades JavaScript
├── robots.txt          # Configuración para motores de búsqueda
├── sitemap.xml         # Mapa del sitio para SEO
├── images/             # Directorio de imágenes (crear localmente)

```

## 🔧 Desarrollo local

1. Clona el repositorio:
```bash
git clone https://github.com/TU_USUARIO/tapiceriaelcarmen.git
cd tapiceriaelcarmen
```

2. Abre `index.html` en tu navegador o usa un servidor local:
```bash
# Con Python
python3 -m http.server 8000

# Con Node.js
npx http-server
```

3. Accede a `http://localhost:8000`

## 📤 Despliegue

El sitio se despliega automáticamente a través de **Cloudflare Pages** conectado a este repositorio de GitHub.

### Flujo de despliegue automático:
1. Haces cambios en tu código localmente
2. Haces commit y push a GitHub
3. Cloudflare Pages detecta los cambios automáticamente
4. Cloudflare construye y despliega la nueva versión
5. El sitio se actualiza en https://tapiceriaelcarmen.com

### Configuración de build en Cloudflare Pages:
- **Framework preset**: None
- **Build command**: (vacío)
- **Build output directory**: `/`
- **Root directory**: `/`
